COMMON->MARS 使用位置映射

源码范围：LMDZ.COMMON-6.3\LMDZ.COMMON 与 LMDZ.MARS。 用途：从 COMMON 文件或模块反查 MARS 侧的直接使用位置、路径转发和相关复现链路。

使用方式

  • 直接转发 表示 MARS 文件内容直接指向 COMMON 文件。
  • USE/CALL 表示 MARS 源码中搜索到模块或例程使用点。
  • 同名变体 表示 MARS 与 COMMON 中其他行星目录存在同名流程文件，不能自动视为相同实现。

COMMON 区域级使用图

COMMON 区域 MARS 使用形态 当前证据 文档说明
libf\dyn3d_common MARS 1D dyn wrapper 直接转发；MARS lon-lat phymars 通过 USE 使用状态模块 直接路径转发 10 个；USE comconst_mod/comvert_mod/control_mod/infotrac 多处 以状态页、垂直坐标页、tracer 页和 Mars utility 页交叉覆盖。
libf\dyn3d MARS 1D dyn wrapper 转发 abort_gcm.F、logic_mod.F90；MARS phymars nogcm/leapfrog_nogcm 使用串行动力逻辑 直接路径转发 2 个；CALL abort_gcm 多处 串行入口、控制逻辑和错误处理页共同说明边界。
libf\dyn3dpar MARS 1D 物理测试复用 MPI 常量和 parallel abstraction 直接路径转发 mod_const_mpi.F90、parallel_lmdz.F90；testphys1d USE 并行抽象页需显式说明 1D 串行/占位使用场景。
libf\dynphy_lonlat MARS phymars 有自己的行星实现，同时复用 COMMON 接口模块和几何初始化 mod_interface_dyn_phys 直接转发；CALL inigeomphy；同名 Venus/Titan 文件 目录页把 shared interface 与 planet-specific variants 分开。
libf\phy_common MARS 使用关系主要来自物理侧输出、网格、transfer 和 getin 边界 输出、并行公共层、XIOS/getin 页面已有覆盖 以物理公共层组页和 restart/history 主题维护。
libf\misc MARS 使用关系主要表现为通用库、NetCDF/ioipsl 和 write_field write_field 在 phymars\leapfrog_nogcm.F 中可见 以 NetCDF/getin/write_field 工具页维护。
