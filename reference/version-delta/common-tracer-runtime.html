COMMON tracer 与通用运行时

页面定位

覆盖 tracer 文件解析、字符串工具、命令行选项和作业运行时支持。

兼容性关注：影响 tracer 元数据来源、公共解析接口和运行时辅助能力。

本页是 5.3 到 6.3 版本差异详情页，只解释改动职责与影响，不展开逐行代码差异。

变化统计

本主题覆盖 4 个路径事件：新增 4、删除 0、修改 0。

主要变化

  • libf/misc/job.F90：新增作业环境模块，识别 SLURM/PBS 作业号与时限，解析 days-hours:minutes:seconds，并提供提前终止所需的 timelimit/timewall 状态。
  • libf/misc/program_options.F90：新增通用命令行选项模块，解析帮助、并行布局和运行参数并提供 usage 输出，供动力主程序启动时调用。
  • libf/misc/readTracFiles_mod.f90：新增公共 tracer.def/traceur.def 解析设施，供 MARS 物理侧新格式解析调用。
  • libf/misc/strings_mod.f90：新增通用字符串与消息模块，提供大小写转换、裁剪/清洗、分割/堆叠、查找替换、计数解析及分级输出工具。
