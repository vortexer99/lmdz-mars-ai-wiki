COMMON 物理侧并行与传输

页面定位

覆盖 MPI、OpenMP 及组合并行的数据广播、分发、收集和控制状态。

兼容性关注：影响混合并行正确性、物理列通信和 XIOS/getin 广播。

本页是 5.3 到 6.3 版本差异详情页，只解释改动职责与影响，不展开逐行代码差异。

变化统计

本主题覆盖 9 个路径事件：新增 0、删除 0、修改 9。

主要变化

  • libf/phy_common/abort_physic.F90：调整物理侧终止诊断的标点和错误码文字，不改变 MPI_ABORT 与串行停止分支。
  • libf/phy_common/geometry_mod.F90：新增线程私有 cell_area_for_lonlat_outputs，并提供初始化入口保存含复制极点的经纬网输出面积，避免改变物理 cell_area。
  • libf/phy_common/init_print_control_mod.F90：把 lunout、prt_level 和 debug 改为初始化例程内的局部默认值，再通过 getin_p 读取覆盖值，避免依赖模块中的预置状态。
  • libf/phy_common/ioipsl_getin_p_mod.F90：统一 getin_p 的主控判断：所有标量/数组读取从 MPI-root 与 OMP-root 联合条件迁到 mod_phys_lmdz_para:is_master。
  • libf/phy_common/mod_phys_lmdz_mpi_transfert.F90：更新源码文件 mod_phys_lmdz_mpi_transfert.F90：新增 bcast_mpi_i5、bcast_mpi_i6、bcast_mpi_r5、bcast_mpi_r6；移除 grid2dTo1d_mpi_r3、grid2dTo1d_mpi_l、grid2dTo1d_mpi_l1、grid2dTo1d_mpi_l2。
  • libf/phy_common/mod_phys_lmdz_omp_transfert.F90：新增 5/6 维 OMP 广播，并把缓冲增长因子改为实数、分配区改用 SINGLE 同步，修正并行缓冲扩容与可见性。
  • libf/phy_common/mod_phys_lmdz_para.F90：在 MESOSCALE 构建中跳过 Test_transfert 并行传输自检，其他构建仍保留该初始化检查。
  • libf/phy_common/mod_phys_lmdz_transfert_para.F90：更新源码文件 mod_phys_lmdz_transfert_para.F90：新增 bcast_i5、bcast_i6、bcast_r5、bcast_r6。
  • libf/phy_common/print_control_mod.F90：更新源码文件 print_control_mod.F90中的 print_control_mod、set_print_control：外部模块、例程、调用和 getin 键集合保持不变，差异集中在局部声明、维度或类型约束。
