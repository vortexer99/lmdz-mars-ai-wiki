MARS 顶层结构、配置与平台

页面定位

覆盖 deftank、datadir、startfiles、平台脚本、样例配置和顶层文档。

兼容性关注：影响运行目录组织、配置键、样例默认值和集群作业启动。

本页是 5.3 到 6.3 版本差异详情页，只解释改动职责与影响，不展开逐行代码差异。

变化统计

本主题覆盖 50 个路径事件：新增 22、删除 8、修改 20。

主要变化

  • 顶层 README 的历史记录职责拆分到 changelog.txt；deftank/z2sig.def 的等内容样例在 6.3 以 z2sig.def.MCD6 命名。
  • XIOS XML 从 deftank/ 根目录集中到 deftank/xios/，context 文件同时采用 context_pcm_physics.xml 名称。
  • changelog.txt：新增独立 Changelog 文件；其前缀继承 5.3 README 中的历史记录。
  • datadir/README：新增 datadir 获取说明，指向官方在线火星运行数据归档，而不在源码树内复制整套数据。
  • deftank/adastra/adastra_cpu_binding.sh：新增 Slurm CPU/GPU 亲和性包装脚本，按本地 rank 与 MPI/OpenMP 组合选择 NUMA CPU 集合，并在需要时绑定 GPU。
  • deftank/adastra/README：新增 Adastra 运行目录说明，描述 GCM 作业脚本、逐月续跑方式及需要按账户和队列调整的参数。
  • deftank/adastra/run0：新增运行脚本 run0，用于 deftank/adastra 下的环境准备、作业提交或续跑流程；该脚本进入 6.3。
  • deftank/adastra/run_month1：新增运行脚本 run_month1，用于 deftank/adastra 下的环境准备、作业提交或续跑流程；该脚本进入 6.3。
  • deftank/adastra/run_year1：新增运行脚本 run_year1，用于 deftank/adastra 下的环境准备、作业提交或续跑流程；该脚本进入 6.3。
  • deftank/callphys.def.co2clouds.GCM5：更新运行配置或作业样例 callphys.def.co2clouds.GCM5：新增配置项 outputs_per_sol、max_icecap_albedo、reff_lift_dust、albedo_h2o_cap、call_mass_fixer_dyn；移除配置项 tracer、lwrite、albedo_h2o_ice、thermoswater。
  • deftank/callphys.def.GCM5：由旧 callphys.def.watercycle 重命名为 GCM5 配置模板，明确其对应 CO2、尘埃和水循环组合。
  • deftank/callphys.def.GCM6：更新运行配置或作业样例 callphys.def.GCM6：新增配置项 outputs_per_sol、calllott_nonoro、nonoro_gwd_epflux_max、nonoro_gwd_sat、nonoro_gwd_rdiss、nonoro_gwd_kmax、nonoro_gwd_kmin、nonoro_gwd_xlaunch、max_icecap_albedo、reff_lift_dust、temp_dependent_m、cloud_adapt_ts、albedo_h2o_cap、call_mass_fixer_dyn；移除配置项 tracer、lwrite、temp_dependant_m、albedo_h2o_ice、thermoswater。
  • deftank/callphys.def.hdo.GCM5：更新运行配置或作业样例 callphys.def.hdo.GCM5：新增配置项 outputs_per_sol、max_icecap_albedo、reff_lift_dust、albedo_h2o_cap、call_mass_fixer_dyn；移除配置项 tracer、lwrite、albedo_h2o_ice、thermoswater。
  • deftank/callphys.def.MCD5：更新运行配置或作业样例 callphys.def.MCD5：新增配置项 outputs_per_sol、max_icecap_albedo、reff_lift_dust、albedo_h2o_cap、call_mass_fixer_dyn；移除配置项 tracer、lwrite、albedo_h2o_ice、thermoswater。
