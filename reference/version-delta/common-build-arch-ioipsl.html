COMMON 构建、arch 与 IOIPSL

页面定位

覆盖 FCM 构建入口、机器配置和 IOIPSL 安装/链接支持。

兼容性关注：影响编译命令、平台环境、I/O 后端选择和可移植性。

本页是 5.3 到 6.3 版本差异详情页，只解释改动职责与影响，不展开逐行代码差异。

变化统计
