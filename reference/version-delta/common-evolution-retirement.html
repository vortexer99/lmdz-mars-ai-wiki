COMMON evolution 目录退出

页面定位

覆盖 5.3 中随 COMMON 分发、6.3 中不再保留的 evolution/PEM 文件群。

兼容性关注：证明目录从当前 COMMON 树退出；不能单独证明相关能力被废弃。

本页是 5.3 到 6.3 版本差异详情页，只解释改动职责与影响，不展开逐行代码差异。

变化统计

本主题覆盖 15 个路径事件：新增 0、删除 15、修改 0。

主要变化

  • libf/evolution/compile：移除旧 evolution/PEM 组件 compile；其构建、调度或演化辅助职责不再由 6.3 COMMON 树中的该路径提供。
  • libf/evolution/compute_tendencies_mod.F90：移除源码文件 compute_tendencies_mod.F90，其中定义 compute_tendencies；该实现不再随 6.3 分发。
  • libf/evolution/compute_tendencies_mod_slope.F90：移除源码文件 compute_tendencies_mod_slope.F90，其中定义 compute_tendencies_slope；该实现不再随 6.3 分发。
  • libf/evolution/conf_evol.F90：移除源码文件 conf_evol.F90，其中定义 conf_evol；该实现不再随 6.3 分发。
  • libf/evolution/criterion_ice_stop_mod_slope.F90：移除源码文件 criterion_ice_stop_mod_slope.F90，其中定义 criterion_ice_stop_slope；该实现不再随 6.3 分发。
  • libf/evolution/criterion_ice_stop_mod_water_slope.F90：移除源码文件 criterion_ice_stop_mod_water_slope.F90，其中定义 criterion_ice_stop_water_slope；该实现不再随 6.3 分发。
  • libf/evolution/dimension_mod.F90：移除源码文件 dimension_mod.F90，其中定义 dimension_mod、init_dim；该实现不再随 6.3 分发。
  • libf/evolution/evol_co2_ice_s_mod_slope.F90：移除源码文件 evol_co2_ice_s_mod_slope.F90，其中定义 evol_co2_ice_s_slope；该实现不再随 6.3 分发。
  • libf/evolution/evol_h2o_ice_s_mod_slope.F90：移除源码文件 evol_h2o_ice_s_mod_slope.F90，其中定义 evol_h2o_ice_s_slope；该实现不再随 6.3 分发。
  • libf/evolution/makelmdz_fcm：移除旧 evolution/PEM 目录专用的 FCM 构建驱动；该构建入口随 evolution 子树退出 COMMON。
  • libf/evolution/orbit_param.F90：移除源码文件 orbit_param.F90，其中定义 orbit_param；该实现不再随 6.3 分发。
  • libf/evolution/pem.F90：移除源码文件 pem.F90，其中定义 pem；该实现不再随 6.3 分发。
  • 其余 3 项见下表和全量索引。
