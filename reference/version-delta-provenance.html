文件比较

对相对路径和 SHA-256 进行比较。排除 .git、build、bin、obj、__pycache__、.DS_Store 及常见编译产物。换行、编码或注释变化也会被计为同路径修改，因此矩阵不会自动把哈希变化解释成科学算法变化。

证据等级

标记 含义
官方记录 Changelog 明确出现该文件名或符号名。
官方分组记录 仅用于人工确认同一条官方记录明确覆盖的一组路径；自动生成器不按主题猜测。
间接记录 COMMON 路径在 MARS Changelog 中被直接或按主题提及。
间接记录（分组） MARS Changelog 间接描述 COMMON 相关主题，但没有逐一列出该路径。
源码差异 哈希或路径变化已确认，但未找到对应 Changelog 条目。
